# Tarea: Cálculo de Salario Semanal en Python

**Estudiante:** Ronny Yalama

## Descripción del problema
Este proyecto en Python calcula el salario semanal de un trabajador a partir de las horas trabajadas a la semana y la tarifa de pago por hora, con un valor equivalente a un sueldo mensual de $1100.

El código está estructurado con una función personalizada de dos parámetros (`def`), retorna el valor calculado (`return`) y se ejecuta desde el bloque principal (`if __name__ == '__main__':`).
